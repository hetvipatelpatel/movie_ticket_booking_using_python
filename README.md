## 🎬 Movie Ticket Booking System
A complete **Movie Ticket Booking System** developed using Python.  
This project allows users to book movie tickets online and enables admins to manage movies and theaters efficiently.

## 📌 About the Project
This system is designed with **role-based access**:
- **Admin**
- **User**
Each role has different functionalities to ensure smooth operation of the system.

## 🚀 Features
### 👨‍💼 Admin
- ➕ Add Movies  
- ❌ Delete Movies  
- 🏢 Add Theaters  
- 🗑️ Delete Theaters  
- 📊 Manage system data
  
### 👤 User
- 🔐 User Login  
- 🎟️ Book Tickets for Movies  
- ❌ Cancel Bookings  
- ⭐ Give Reviews & Ratings  
- 📧 Receive Email Confirmation after booking  

## 🛠️ Technologies Used
- Python  
- File Handling / Database (based on your implementation)  
- SMTP (for email sending)  

## 🔑 Login System
- Users must log in to access features  
- Role-based authentication (Admin / User)
  
## 📧 Email Functionality
- After booking a ticket, a confirmation email is sent to the user  
- Uses SMTP for sending emails
